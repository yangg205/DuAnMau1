## 📖 Giới thiệu
DuAnMau1 là dự án game 2D thể loại hành động được phát triển bằng Unity và C#.  
Project tập trung vào xây dựng hệ thống gameplay gồm nhân vật, enemy và boss với cơ chế chiến đấu cơ bản.

## 🎮 Gameplay Features
- Điều khiển nhân vật di chuyển và tấn công
- Hệ thống Enemy AI cơ bản
- Boss với máu và cơ chế chiến đấu riêng
- Hệ thống máu (HP) cho Player và Enemy
- Xử lý va chạm (Collision Detection)
- Quản lý Scene và Game Object

## 🧠 Kỹ thuật đã áp dụng
- Lập trình hướng đối tượng (OOP)
- Tách script theo chức năng (Player, Enemy, Boss, GameManager)
- Sử dụng Rigidbody2D và Collider2D
- Quản lý trạng thái nhân vật (Idle, Move, Attack, Death)

## 🛠 Công nghệ sử dụng
- Unity Engine
- C#
- Git & GitHub
- Visual Studio
